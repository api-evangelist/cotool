# Cotool

> Cotool is an AI platform for the defensive security "blue team" — AI agents that scale detection, response, and threat hunting across an organization's security stack to improve coverage, cut mean-time-to-respond (MTTR), and eliminate manual, repetitive security operations work. Cotool is a San Francisco company backed by Andreessen Horowitz (a16z), Y Combinator, WndrCo, and Homebrew. As of this profile, Cotool publishes a product and marketing site only — no public API, developer documentation, SDK, or MCP server was found.

## Products
- [Detect](https://www.cotool.ai/detect): AI-powered threat detection authored from natural-language descriptions.
- [Respond](https://www.cotool.ai/respond): Automated alert response and playbook execution with human-in-the-loop controls.
- [Hunt](https://www.cotool.ai/hunt): Threat-intelligence monitoring that filters for relevance and surfaces coverage gaps.
